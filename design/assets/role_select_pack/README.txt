Recommended production usage:

2. Use @2x/@3x variants for iOS; keep important artwork inside safe margins.
3. For SwiftUI, use Image assets with template rendering only for monochrome icons.
4. For React Native/Flutter, use PNGs for hero artwork and Lottie for small motion elements.
5. The included hero crops are clean standalone artwork crops from the generated asset sheet; for final production, a designer can re-export the same artwork as true transparent PNG/SVG for maximum fidelity.
